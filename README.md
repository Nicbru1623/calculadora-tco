PUBLICAR GRATIS CON GITHUB PAGES
1. Crea una cuenta en https://github.com si no tienes una.
2. Crea un repositorio nuevo. Por ejemplo: calculadora-tco-Camiones chevrolet
3. Selecciona Public (público) para poder usar GitHub Pages gratis.
4. Sube el archivo index.html incluido en este paquete a la raíz del repositorio.
5. En el repositorio, entra a Settings > Pages.
6. En Build and deployment, selecciona Deploy from a branch.
7. Selecciona la rama main y la carpeta /(root), y guarda.
8. Espera a que GitHub publique la página. La dirección aparecerá en Settings > Pages y normalmente tendrá la forma:
   https://TU-USUARIO.github.io/calculadora-tco-chevrolet/

IMPORTANTE
- El enlace no tiene una fecha de vencimiento programada, pero depende de que la cuenta y el repositorio sigan activos y la publicación se mantenga habilitada.
- No incluyas datos confidenciales de clientes en un repositorio público.
- Esta calculadora usa datos de ejemplo; reemplázalos por datos verificados antes de presentarla como comparación comercial.
